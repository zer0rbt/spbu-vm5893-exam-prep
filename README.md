# Подготовка к вступительному экзамену в магистратуру СПбГУ

Материалы для вступительного испытания по предмету **«Технологии искусственного
интеллекта и Big Data»**, направление 02.04.02 «Фундаментальная информатика и
информационные технологии», программа **ВМ.5893**.

## Формат экзамена

180 минут, письменно, с прокторингом, без использования источников. Три части:

| Часть | Содержание | Баллы |
|---|---|---|
| Научно-исследовательская | эссе: опыт, выбор программы, применение знаний, аннотация ВКР | 30 |
| Теоретическая | два случайных вопроса из разных тем | 40 (по 20) |
| Практическая | одна задача на Python или SQL | 30 |

В поле ответа обязательно указать язык программирования, иначе решение не
оценивается. Текст программы прикладывается файлом с соответствующим расширением
(исполняемый файл не принимается).

## Что внутри

| Файл | Описание |
|---|---|
| [`exam_prep/essay.md`](exam_prep/essay.md) | научно-исследовательская часть: опыт, мотивация, аннотация ВКР и результаты (387 слов при норме 300–600) |
| [`exam_prep/theory.md`](exam_prep/theory.md) | ответы на все 26 вопросов программы: формулировка билета дословно, затем ответ |
| [`exam_prep/theory_simple.md`](exam_prep/theory_simple.md) | та же теория в сжатом виде — шпаргалка для повторения накануне |
| [`exam_prep/examples_from_program.md`](exam_prep/examples_from_program.md) | разбор двух примеров практических заданий из программы: SQL-гистограмма и term frequency; заметки про pandas и диалекты SQL |
| [`exam_prep/analyze_task_1.py`](exam_prep/analyze_task_1.py) | разведочный анализ датасета сделок на pandas, генерирует markdown-отчёт |
| [`exam_prep/analysis_task_1.md`](exam_prep/analysis_task_1.md) | готовый отчёт по `task_1.parquet` |
| [`exam_prep/trades_analysis.py`](exam_prep/trades_analysis.py) | универсальный анализ истории торгов: OHLCV, доходности, волатильность, корреляции, МНК |
| [`exam_prep/sql_playground.py`](exam_prep/sql_playground.py) | SQL-консоль (DuckDB / SQLite) с загруженными данными для тренировки запросов |

Темы теоретической части: основы машинного обучения, теория вероятностей и
математическая статистика, программирование на Python, базы данных,
методологические вопросы разработки ПО, инструменты разработки ПО.

## Данные

Каталог `exam_prep/data/` в репозиторий не входит (см. `.gitignore`). Туда нужно
положить учебные файлы, которые раздаёт факультет:

* `task_1.parquet`, `task_2.parquet` — история торгов на электронной бирже,
  столбцы `timestamp`, `price`, `quantity`, `product_id`;
* `programma_ekzamena.pdf` — программа вступительного испытания.

Скрипты работают с любым parquet такой структуры — путь задаётся аргументом.
`sql_playground.py` без данных тоже запускается: синтетическая БД авиаперевозок
генерируется на лету.

## Установка и запуск

```bash
python3 -m pip install -r requirements.txt

# анализ данных
python3 exam_prep/analyze_task_1.py exam_prep/data/task_1.parquet --md report.md
python3 exam_prep/trades_analysis.py exam_prep/data/task_1.parquet --freq 1h

# SQL-консоль
python3 exam_prep/sql_playground.py
python3 exam_prep/sql_playground.py --engine sqlite
```

Проверено на Python 3.10 (Windows) и Python 3.12 с pandas 3.0 (Ubuntu 24.04).
